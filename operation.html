这页不放排版器本体，只解决使用路径。先让 AI 按公众号结构输出 Markdown，再把内容导入排版器，切风格、调节奏、复制到公众号后台。

进入排版器

发布工作流

按这个顺序走，最快，也最稳。

01

先用提示词生成 Markdown

把下方提示词给 AI，让它直接输出公众号可用的 Markdown 正文，不要额外解释，不要代码围栏。

02

导入正文内容

支持飞书、Notion、Word 直接粘贴，也支持导入 `.md` 文件。富文本会自动转成 Markdown。

03

切换主题并调节节奏

选风格主题，再按需要调整字号、字间距、行高、段间距、标题模块间距和内容宽度。

04

复制到公众号后台

优先用“一键复制到公众号”，这是微信兼容导出；备用 HTML 只用于特殊场景。

支持内容来源

这些入口都已经打通。

飞书

富文本直接粘贴进编辑框，自动转 Markdown。

Notion

标题、列表、引用、表格和链接会一起转换。

Word

优先读取剪贴板里的 HTML 结构，减少格式丢失。

Markdown 文件

支持 `.md`、`.markdown`、`.txt`，导入后可继续编辑。

使用规范

            
这几条会直接影响排版效果。

          

        

        
    
          
  1. 全文只保留一个一级标题，避免标题层级失控。
    2. 
          
  2. 用二级标题切模块，一个模块控制在 2 到 3 段短段落。
    3. 
          
  3. 需要提示块时，用 `:::tip 标题 ... :::` 这种结构。
    4. 
          
  4. 需要插图占位时，用标准 Markdown 图片语法。
    5. 
          
  5. 不要让 AI 输出说明文字、分析过程、代码围栏和多余备注。
    6. 
        

      

    


    

      

        

          

            
发布前检查

            
复制进公众号后台前，建议过一遍。

          

        

        
    
          
  • 深色或重纹理主题，先看手机预览再复制，避免正文密度过高。
    • 
          
  • 表格、提示块、引用块在公众号后台会走兼容样式，优先以导出效果为准。
    • 
          
  • 如果公众号后台里出现图片宽度异常，重新使用“一键复制到公众号”再试一次。
    • 
          
  • 标题过长时，建议手动压缩成两行内，提高手机端阅读效率。
    •
