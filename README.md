# WeType 高级微信公众号排版器

一个专为微信公众号内容创作设计的现代化排版工具，提供专业级的排版效果和极致的用户体验。

## 🚀 产品概述

WeType 是一款高级微信公众号排版器，旨在帮助内容创作者快速生成美观、专业的微信公众号文章。支持 Markdown 编辑、富文本导入、一键复制到公众号后台等核心功能。

### 核心价值

- **专业排版**：提供 15 套精心设计的主题风格，涵盖多种阅读气质
- **高效创作**：支持 Markdown 编辑、富文本导入、AI 辅助写作
- **完美适配**：专门针对微信公众号后台进行优化，确保兼容性
- **极致体验**：现代化界面设计，直观的操作流程

## 🛠️ 使用指南

### 快速开始

1. **访问工具**：打开 https://muziliguoguo-ux.github.io/wechat-editor/
2. **选择主题**：在左侧选择喜欢的主题风格
3. **编辑内容**：在中间区域使用 Markdown 编辑文章
4. **预览效果**：在右侧手机预览区域查看效果
5. **复制文章**：点击"复制到公众号"按钮，直接粘贴到微信后台

### 高级功能

#### 富文本导入
- 直接从飞书、Notion、Word 复制富文本内容
- 系统会自动转换为 Markdown 格式

#### AI 辅助写作
- 点击"AI 生成"按钮（待开发）
- 输入文章主题，AI 会自动生成内容框架

#### 自定义排版
- 调节字体大小、行高、字间距
- 调整段落间距、标题模块间距
- 选择自动标重点功能

### 导出与发布

1. **复制到公众号**：
   - 点击"复制到公众号"按钮
   - 打开微信公众号后台
   - 新建图文消息，粘贴内容

2. **复制 HTML**：
   - 点击"复制备用 HTML"按钮
   - 用于其他平台发布或备份

## 🏗️ 部署说明

### 本地开发

```bash

git clone https://github.com/muziliguoguo-ux/wechat-editor.git

# 进入项目目录
cd wechat-editor
```

## 🔧 开发说明

### 文件结构

```
wechat-editor/
├─ index.html              # 主应用文件
├─ operation.html          # 操作说明
├─ README.md              # 项目说明
└─ .gitignore             # Git 忽略文件
```

### 主要功能模块

1. **主题系统**：`themes` 数组定义主题配置
2. **Markdown 解析**：`parseMarkdown` 函数处理内容
3. **富文本转换**：`convertHtmlToMarkdown` 函数
4. **主题切换**：`setTheme` 函数处理主题变更
5. **预览渲染**：`render` 函数更新预览

### 扩展性

项目架构支持：
- 新增主题：在 `themes` 数组中添加配置
- 新增功能：通过事件监听和 DOM 操作实现
- 样式定制：修改 CSS 变量和样式类
